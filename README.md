## Assignment 9. Product description from photos.
Generate an application, which inputs 1 to many images and then it writes production descriptions and marketing slogans based on those products. Include also user input text, to increase the accuracy of the automatically LLM-generated product descriptions.

### Assignment 10. Output JSON dictionary. 
Generate an application, which inputs a word and then outputs LLM-powered dictionary entry output in JSON format. The application should output valid JSON and nothing else (no preamble). 

#### Assignment 11 Article generator with APA style references PDF

Generate an application, which inputs a topic for a scientific article. It should normal article structure from abstract to conclusions and divided into chapters with subchapters all with their respectable headings. It could also include tables. It must have a reference list and references inside the text body using APA style.
Recommended solution: Prompt the LLM to generate markdown and then convert the markdown into structured PDF document. Check the references. How many of them were hallucinations (wrong)
