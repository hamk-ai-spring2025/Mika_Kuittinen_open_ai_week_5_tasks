## Assignment 9. Product description from photos.
Generate an application, which inputs 1 to many images and then it writes production descriptions and marketing slogans based on those products. Include also user input text, to increase the accuracy of the automatically LLM-generated product descriptions.

### Assignment 10. Output JSON dictionary. 
Generate an application, which inputs a word and then outputs LLM-powered dictionary entry output in JSON format. The application should output valid JSON and nothing else (no preamble).
